# Resident Evil 2 - MOD Latino para PS4

MOD de doblaje en español latino para Resident Evil 2 (2019) en PS4. Reemplaza todos los audios del juego en inglés por una adaptación completa al español, con voces originales de la comunidad de doblaje hispanohablante.

## Características

- Doblaje completo al español latino
- Compatible con la versión 1.07 del juego (funciona como versión 1.08)
- Instalación mediante plugin AFR (GoldHen) o juego completo pre-modificado
- Incluye voces de actores de México, Chile, Argentina, Ecuador, El Salvador y Perú

## Métodos de instalación

### A. Mediante el Plugin de AFR

Recomendado para quienes ya tienen el juego o suelen colocar más mods. No importa ni el ID ni la versión del juego.

1. Entra en PS4 Explorer y en `/data/GoldHen/` crea un archivo vacío llamado `plugins.ini`
2. Instala y ejecuta `plugins by kizeo.pkg`
3. Edita `plugins.ini` y agrega tu CUSA + la ruta del plugin
4. Crea la carpeta CUSA dentro de `/data/GoldHen/AFR/` y coloca los archivos del mod
5. Renombra los archivos según tu versión de juego (versión + 1)
6. Activa el plugin en GoldHen y ejecuta el juego

### B. Juego Completo Ya Editado

Juego completo que ya incluye el MOD LATINO.

- **ID:** CUSA09171
- **Versión:** 1.07 (1.08 con el mod)
